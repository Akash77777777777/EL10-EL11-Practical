# Frequently Asked Questions (FAQ)

## 1. What is GitHub Pages?

GitHub Pages is a hosting service that allows users to publish static websites directly from GitHub repositories.

## 2. Is GitHub Pages free?

Yes. GitHub Pages is available for public repositories on the GitHub Free plan.

## 3. Which files are used for documentation?

Markdown files with the `.md` extension are used for documentation.

## 4. What is the docs folder?

The docs folder contains documentation files that can be published using GitHub Pages.

## 5. How can I access the website?

After enabling GitHub Pages, open the generated website URL.
