# Code of Conduct

## Our Pledge

We are committed to providing a friendly, safe and welcoming environment for everyone.

## Expected Behaviour

- Be respectful and considerate.
- Use welcoming and inclusive language.
- Respect different opinions.
- Accept constructive feedback.
- Help other contributors.

## Unacceptable Behaviour

- Harassment or discrimination.
- Offensive comments.
- Personal attacks.
- Sharing inappropriate content.

## Reporting Issues

If you notice unacceptable behaviour, contact the repository owner through GitHub.

GitHub Profile: https://github.com/Akash77777777777

## Enforcement

The repository owner is responsible for reviewing reported issues and taking appropriate action.

## Scope

This Code of Conduct applies to all project contributors and participants.
